# 权限设置与引导窗口

本轮处理两项授权体验：去掉进入设置时重复的授权提示；对应权限实际生效后自动关闭引导。

## 行为

屏幕录制、辅助功能、输入监控入口保留释放远程输入和跳转对应系统设置页面的流程，删除主动调用的 `CGRequestScreenCaptureAccess`、带 prompt 的 `AXIsProcessTrustedWithOptions` 和 `IOHIDRequestAccess`。设置入口仍可显示尚未生效的拖拽引导，不再叠加系统授权请求。开启共享时若缺录屏权限，保留状态与诊断记录并前往设置，不再额外生成应用的“知道了”弹窗；其他配置错误仍沿用原失败提示。

PermissionGuide 按当前显示的权限项查询实际状态。已经生效时不显示；可见后检测到生效则关闭，切换项时只以新项状态为准。手动关闭后刷新不会重新弹出。仍保留拖拽图标、当前应用路径、手动重新检测以及非激活浮窗行为。

继续使用现有约两秒计时器与返回应用、唤醒时的检查，不增加新的常驻轮询。计时器先保存浮窗是否可见，再执行本轮模型刷新，保证录屏状态在自动关窗的这一轮同步写回；没有浮窗、连接或 Caps Lock 需求时不额外查询。辅助功能控制状态订阅、Caps Lock 和系统快捷键的真实权限检查及恢复流程保留。

系统勾选但当前进程还未生效时不会自动关闭。应用不会给系统授予权限或修改隐私数据库；实际采集期间 macOS 自身的提醒或重启要求仍由系统控制。

## 验证

- 修改前工作树与暂存区为空，仅按两项需求和检查接入修改必要文件；两项功能分别本地提交，未推送。
- 完整应用编译通过；应用未引用上述三个主动授权 API。
- `scripts/run-permission-checks.sh`：10 项合成状态面板检查通过，0 失败，并通过设置入口静态 API 检查。覆盖三类权限未生效/生效、初始已生效不显示、切换当前项、切换到已生效项、手动关闭不重开与非激活浮窗属性。
- 测试使用 `local.quietdesk.checks.permission-guide` 独立 bundle ID、透明 1 像素面板和显式合成状态，不运行生产应用，不查询、授予或重置真实权限，不打开系统设置。
- 沙箱内 AppKit 的 LaunchServices 注册受限；在允许 AppKit 的本机环境运行独立测试后通过。未将该环境失败当作权限逻辑缺陷，也未用静态检查代替面板检查。
- 脚本语法、差异检查和工作流 YAML 解析通过；未触发远端 CI 或发布。
- 实际用户在系统设置中授权、进程需重启时的行为、双机权限变化与监听恢复尚未实机验收；没有中断用户现有连接。
