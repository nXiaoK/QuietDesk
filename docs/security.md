# 安全与限制

## 连接与凭据

- TCP 连接使用系统 Network.framework 的 **TLS 1.2 / PSK / AES-128-GCM**。配对码由 **256 位随机数**生成，等同于控制凭据；只应通过可信渠道传递。新版视频 UDP 使用 **DTLS 1.2 / PSK / AES-128-GCM**，在已经配对认证的 TCP 控制连接内交换每个会话独立生成的随机媒体密钥与绑定令牌；这些会话材料不写入凭据文件或日志。
- 主机配对码与快捷连接凭据改为保存在本机 `~/Library/Application Support/QuietDesk/Credentials/pairing-codes.json`。目录权限为 `0700`，文件权限为 `0600`，仅当前账户可访问；内容是明文，没有单独加密，同账户的其他进程仍可能读取。
- 应用不再查询、写入或删除钥匙串凭据。旧钥匙串条目保持不动；升级后手动补录原配对码一次，连接记录和画质偏好保留。缺少主机码时不会自动生成或开启共享，避免无提示更换原码；只有明确点击生成新码才会换码。
- 当前 PSK 套件**不提供前向保密**。配对码泄露可能使他人建立连接，也可能影响此前被记录的加密流量；停止共享后可重新生成配对码，使旧码失效。媒体使用临时会话密钥不改变这一限制，因为密钥由上述 TCP 连接交换。
- 复制配对码时使用仅限本机的剪贴板，并附加 Concealed / Transient 隐私标记；60 秒后仅在剪贴板未变化时清除。QuietDesk 的自动和手动发送都会跳过带这些敏感标记的内容。
- 局域网可直接使用被控 Mac 的 IP 和监听端口，默认数字端口为 `5908`。新版共享在同一数字端口接受 TCP、UDP；公网映射需将同一外部端口的两种协议转发到同一被控端监听端口。只有 TCP 可达时保留 TCP 路径。共享会监听本机可用网络接口，请仅开放需要的端口。应用不提供中转服务或 NAT 穿透，不依赖云账号，也不会自动配置路由器。
- 入站连接在派发到界面线程前预留认证名额，最多同时等待 4 个；同一远端地址每 10 秒最多开始 3 次认证。已有控制会话时，新入站认证等待缩短为 5 秒。这只限制握手资源，不替代系统防火墙。
- 独立 TCP 视频和文件通道按 ALPN 角色与当前控制会话绑定；UDP 通过系统 DTLS 完成加密认证。媒体封装还核对会话、传输代次、编码代次、帧身份与分片边界，缓存、修复次数和接收队列均有限。过期参考链通过新关键帧恢复，旧会话或旧代次的回调不得提交当前画面。更多实现与验证边界见 [UDP/TCP 传输说明](udp-tcp-transport.md)。

## 权限、输入与文件

- 被控端需屏幕录制权限才能共享，需辅助功能权限才能接收键鼠控制。控制端的 Caps Lock 与全屏系统快捷键捕获还需本机辅助功能和输入监控权限。权限由用户在 macOS 中授予，以应用检测到的实际状态为准。UDP/TCP 自动传输不新增系统权限要求，键鼠与会话控制始终走可靠 TCP。
- 独立光标按能力协商，通过现有加密控制连接传输有尺寸限制的形状和归一化位置；离开共享显示器时不读取形状，不移动控制端物理指针。形状缺失时使用通用箭头，不推断系统光标可见性，不新增授权请求。边界见 [独立光标说明](independent-cursor.md)。
- 全屏且远程画面聚焦、权限生效时，⌘空格、⌘Tab 等组合转发到远端；普通窗口、安全输入或系统保留行为仍受 macOS 限制。**⌃⌥Esc 释放控制、⌃⌘F 退出全屏保留在控制端**；离焦、断开或权限失效时释放远端按键。
- 文件和文件夹需要接收方逐次确认，确认前只发送元信息；下载前检查接收卷可用空间，后续写入失败仍取消并清理半成品。暂不支持符号链接等特殊文件，也不支持断点续传。
- 新版未完成数据放在带进程租约的独立目录；同步初始化时只清理能独占租约的崩溃残留，保留其他活跃实例和旧版无租约目录。已经接收的文件继续由用户在接收目录中管理，不自动删除。
- 自动文字同步上限为 16 MiB，图片为 64 MiB；超过后提示保存为文件再复制。系统剪贴板访问仍在主线程，图像转换与网络分块在后台处理。

## 本机效果与功能边界

- 防窥使用**软件黑色窗口遮罩**，不等同于关闭物理显示器，不能保证遮住 Mission Control 或系统安全界面。被控 Mac 可按 **⌃⌥Esc** 退出，断开时撤除。开启时从远端画面排除 QuietDesk 自身窗口，处理被控端的文件确认或权限设置前请先关闭。
- 会话静音作用于默认输出与系统提示音设备，结束后尝试恢复原状态。设备移除、驱动拒绝、控制进程与恢复子进程同时结束或断电，仍可能使恢复失败或延迟；此功能不传输远端音频。
- 当前共享单个显示器并接受一个控制会话。不支持锁屏后或登录窗口中的远程控制、FileVault 解锁、HDR、远程切换显示器及完整触控板手势。画面使用有损 **H.264 / 4:2:0**，原分辨率、高码率和 60 fps 不代表无损画质或保证持续帧率。

## 兼容与签名

- 涉及对端的新功能按能力协商启用，旧端缺少能力时沿用兼容选项。UDP/TCP 新媒体、软件遮罩、会话静音、空闲暂停和新增画质档位需两端支持，建议双方更新。新版辅助通道不可用时可以在控制 TCP 内使用新媒体封装；旧端继续使用原视频消息格式。
- 仓库默认构建与自动发布使用临时签名，**未经过 Apple 公证**。本地使用固定证书签名也不等于完成 Developer ID 分发与公证，不能保证跨版本、路径或系统更新后保留隐私授权；授权是否生效仍以 macOS 的实际检测为准。
